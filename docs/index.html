Got Questions?

Honest answers

Transparent about how SQUARES Vault works and what we do with your data.

No. When you upload a document, it is processed in memory by the AI to extract metadata — title, dates, amounts, category. The file is then immediately uploaded to your personal Google Drive. We do not keep a permanent copy on our servers. The only data we store is the extracted metadata and the Google Drive file ID that points back to your Drive.

No. Document processing uses Google's enterprise Gemini API. Under enterprise API terms, your data is processed only to return a response and is never used to train or improve any public AI models.

We request only two narrowly-scoped permissions: drive.file — which only allows accessing files SQUARES Vault itself created — and drive.appdata — for configuration sync. We cannot read, see, or modify any other file in your Google Drive.
